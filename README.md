# Voxatelier — KV6 & VXL Voxel Studio

3D model renderer and shader studio for Voxlap `.kv6` and Ace of Spades `.vxl` voxel files.

**▶ Just want to use it?** Open [`index.html`](./index.html) — double-click it, or visit the
[GitHub Pages site](https://kyrope01.github.io/AoS-Map-Renderer/). No install or build needed.

## Why did `index.html` used to show a blank white page?

This project is written in TypeScript/JSX and built with [Vite](https://vite.dev). Browsers cannot
execute TSX source directly — the code must first be **compiled** ("built") into plain JavaScript.
The original root `index.html` was only a *Vite source entry*; it pointed at `/src/main.tsx`, which a
browser can't run, so nothing rendered and even the stylesheet never loaded (hence the white page
instead of the dark UI). The same thing happened on GitHub Pages because Pages was serving the raw
repository contents.

### How it works now

- `app.html` is the Vite source entry (used by the dev server and the build).
- `npm run build` compiles the app and inlines all JS/CSS into a single self-contained
  **`index.html`** at the repo root (see `scripts/inline-build.mjs`). Everything is inline because
  browsers refuse to load external ES modules from `file://` pages.
- That built `index.html` is committed, so the repository works without any tooling: double-clicking
  it locally and GitHub Pages (which serves the repo root of `main`) both just work.

## Developing

```bash
npm install
npm run dev        # http://localhost:3000 → serves app.html with hot reload
npm run lint       # typecheck (tsc --noEmit)
npm test           # parser/mesher unit tests
npm run build      # rebuild the standalone index.html
```

After changing anything in `src/`, run `npm run build` and commit the regenerated `index.html`
together with your source changes — that keeps the double-clickable page and the Pages site in sync.

## Project layout

| Path | Purpose |
| --- | --- |
| `index.html` | Prebuilt standalone app (generated by `npm run build`, committed on purpose) |
| `app.html` | Vite source entry → `src/main.tsx` |
| `src/voxel/` | KV6/VXL parsers, greedy mesher, export resolution math |
| `src/renderer/` | three.js viewport, shader library, lighting/shadow helpers |
| `src/components/` | UI (top bar, control sidebar, light panel) |
| `scripts/inline-build.mjs` | Inlines the Vite build into the standalone `index.html` |
